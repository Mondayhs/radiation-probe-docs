# 第一次 CRP 測試

**目標：** 在有經驗的成員指導下，確認板件資訊、通訊、HK、SCI 產生與讀回，以及測試紀錄的可追溯性。

!!! danger "請勿只依本站說明直接供電或燒錄"
    本公開指南尚未包含核准的接腳配置、供電電壓／電流限制、儀器設定、適用 PCB 版本及完整測試程序。操作前必須先取得正式文件，並由負責人確認。

## 一、測試前確認

- [ ] 記錄測試日期、操作人員、板件版本與序號。
- [ ] 確認韌體 Commit／Tag、ICD 及 GUI／Parser 版本。
- [ ] 取得核准的接線、接地、供電及量測儀器配置。
- [ ] 確認原始 Log 的儲存位置與命名方式。
- [ ] 由資深成員確認操作步驟。

## Windows 測試 GUI（免安裝 Python）

目前已有中、英文兩個 Windows 獨立執行版本。新人**不必另外安裝 Python**，但需先取得完整的測試套件並解壓縮；不可只複製 EXE，必須保留套件中的附屬檔案。USB-to-RS422 轉接器仍可能需要安裝專用驅動程式。

經授權的成員可參閱[私有工程文件：Windows GUI 啟動與設定指南](https://github.com/Mondayhs/radiation-probe-engineering/blob/main/05-Software-Guides/CRP_GUI_WINDOWS_STANDALONE.md)，其中說明 COM Port、預期 UART 115200／8N1 設定，以及測試 Log 的儲存位置。

!!! info "GUI 不等於硬體測試已通過"
    本網站只提供新人導覽。實際供電與接線需依核准 SOP，科學量測結果仍須比對 ICD、原始封包與測試版本。

## 二、測試流程概要

1. **外觀與版本確認：** 依核准圖面檢查板件與連接器。
2. **依正式程序供電：** 由具備資格的成員確認供電條件。
3. **通訊確認：** 使用核准且不會造成破壞性影響的指令檢查連線。
4. **HK 確認：** 保存原始封包，確認解析結果、狀態及時間資訊。
5. **SCI 確認：** 驗證新科學紀錄的產生及讀回，避免把舊資料誤認為新量測。
6. **保存資料：** 留下原始通訊、解析結果、測試設定與異常紀錄。

## 三、如何判斷測試是否有效？

- SCI 是新增紀錄，還是 Parser 重複顯示舊資料？
- RADFET 與參考電壓的換算結果是否合理？
- SCI 讀回資料的紀錄編號與時間能否對應？
- 測試期間是否發生 Reset 或 Mode 變更？
- 其他成員能否依相同版本與條件重現結果？
