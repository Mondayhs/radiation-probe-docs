# 存取權限與公開原則

本站採用**公開入門教學、私有工程資料**的方式管理。

## 公開教學網站

持有網址的人可以直接閱讀，不需要登入 GitHub。不過，本網站仍屬**公開網頁**，其他人可能透過分享連結或 GitHub 取得內容。

本站已加入要求搜尋引擎不收錄的設定，但**無法保證完全不會出現在搜尋結果**，也不等於具備密碼保護。

## 私有工程 Repository

- [DSRP／CRP 工程文件庫](https://github.com/Mondayhs/radiation-probe-engineering)（Private；已建立文件分類與範本，正式 ICD、測試 SOP 及報告待補）

- [CRP 韌體與硬體專案](https://github.com/Mondayhs/compact-radiation-probe)（Private，需取得權限）
- [DSRP／CRP 測試 GUI](https://github.com/Mondayhs/DSRP-CRP-GUI)（Private，需取得權限）

**提供私有 Repository 的連結，不代表對方自然擁有讀取權限。** 請洽專案維護者申請。

## 公開前檢查

- [ ] 是否已取得團隊同意，可以對外公開？
- [ ] 是否含有尚未公開的電路、指令介面、測試結果、帳密或個人資料？
- [ ] 是否標示文件版本及適用系統？
- [ ] 外部圖片、影片與文件是否允許公開引用？

請勿為了讓新進成員方便閱讀，就把私有程式碼或未核准公開的工程文件直接複製進本站。
