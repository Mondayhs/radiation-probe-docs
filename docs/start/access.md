# Access Policy | 公開與私有資料

## Public website

本網站可供持有網址的新人閱讀，也可能被搜尋引擎發現。請只放已確認可公開的教育性內容、版本索引與說明。

## Private engineering repositories

- CRP source and hardware: [compact-radiation-probe](https://github.com/Mondayhs/compact-radiation-probe) (**private; members only**)
- Test GUI: [DSRP-CRP-GUI](https://github.com/Mondayhs/DSRP-CRP-GUI) (**private; members only**)

Private links do not grant access. Contact the project maintainer to request appropriate repository permissions.

## Before publishing a file

- [ ] Is the file approved for public distribution?
- [ ] Does it reveal sensitive integration interfaces, unpublished results, credentials, or personal information?
- [ ] Is the file version clearly identified?
- [ ] Are third-party images and documents licensed for publication?

**Never copy private GitHub source files into this public website just to bypass access control.**
