# DSRP 與 CRP 任務介紹

## DSRP：Deep Space Radiation Probe（深空輻射探測儀）

DSRP 曾搭載於 HAKUTO-R Mission 2 月球任務，主要透過 RADFET 觀測總游離輻射劑量（Total Ionizing Dose, TID），並利用 NAND Flash 研究單粒子翻轉（Single-Event Upset, SEU）現象。

DSRP 的實飛經驗與異常資料，是後續 CRP 改版的重要依據。正式研究引用仍應以原始飛行資料與核准的分析報告為準。

## CRP：Compact Radiation Probe（小型輻射探測儀）

CRP 是延續 DSRP 量測概念、因應 COSPAR-1 CubeSat 平台重新設計的輻射酬載。除保留 RADFET 與 NAND Flash 量測外，也著重韌體穩定性、異常恢復、資料驗證及衛星介面整合。
